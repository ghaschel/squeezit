# Changelog

## [2.5.0](https://github.com/ghaschel/squeezit/compare/v2.4.3...v2.5.0) (2026-10-30)

### Features

- Add lossless QPDF optimization to the CLI, JS/TS API, and all ten existing
  integrations: Babel, Gulp, Grunt, Rollup, Parcel, Vite, Webpack, esbuild, Astro,
  and Next.js.
- Preserve PDF content and metadata without image resampling or lossy
  re-encoding. Standard uses Flate level 6; max compares levels 6 and 9.
- Conservatively skip encrypted PDFs, signatures and blank signature fields,
  timestamps, XFA, previous cross-reference revisions, and inconclusive
  inspection. Expose optional `skipReason` while retaining existing contracts.
- Inspect an immutable snapshot and recheck source identity before publication
  or an inspected skip. Preserve dry-run, threshold, and output-directory behavior.

### Fixes

- Preserve APNG animation during metadata stripping.
- Preserve AVIF 12-bit samples and retained EXIF metadata during optimization.
- Respect supplied Gulp buffers and streams, preserve consumed Parcel streams,
  and restrict Rollup reference rewriting to text assets.
- Keep Git hooks enabled during release changelog amendments and stop release
  preparation when an amendment fails.

### Dependencies and compatibility

- Refresh compatible npm dependencies and native optimizer targets. Add QPDF
  12.4.2 as the tested target with 11.3.0 as the supported minimum.
- Pin Bun 1.4.4 and development/standalone Node 24.22.2 while retaining consumer
  support for Node >=22.13.0.
- Add Babel 8, Astro 7, esbuild 0.28, and TypeScript 6 compatibility while
  retaining the previously supported host versions.
- Keep TypeScript 7, development ExifTool releases, and unreleased Gifsicle
  versions held. Record all parent-constrained dependencies in the
  [dependency hold register](https://github.com/ghaschel/squeezit/blob/main/docs/maintenance/dependency-refresh/dependency-holds.md).

### Documentation

- Add a [PDF guide](https://github.com/ghaschel/squeezit/blob/main/docs/pdf.md)
  and integrate plans, dependency audits, and validation records into the
  existing documentation structure. Internal records are excluded from npm.
- Document preserved integration boundaries: Next.js uses Webpack, Astro
  supports static output, and post-write adapters retain their filename/hash
  limitations. PDF losslessness preserves content, not the original bytes.
